# ctf-toolkit-and-concepts
A curated collection of CTF tools, scripts, and core concepts across web, crypto, pwn, forensics, and reverse engineering, built for learning the fundamentals and quick reference.

## Repository Structure

```
ctf-toolkit-and-concepts/
├── README.md
├── LICENSE
├── concepts/
│   └── client-side-information-leaks.md
│   └── images
├── tools/
│   └── decoder/
├── questions/
│   └── cylab-academy/
```

| Folder | What's inside |
|---|---|
| [`concepts/`](concepts/) | Notes that explain how and why a vulnerability or technique works, with examples |
| [`tools/`](tools/) | Scripts and utilities I've written or collected for solving challenges |
| [`writeups/`](writeups/) | Challenge walkthroughs, organized by platform |
| [`images/`](images/) | Screenshots and diagrams used in the notes |

For educational purposes only. Only test systems you own or have explicit permission to test, and practice on legal platforms and official CTF events. Flags and solutions from active competitions are not published here.
